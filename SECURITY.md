# Security Policy

## Supported scope

Agent Office World is a portfolio demonstrator with a browser-side deterministic simulation. It does not currently operate a backend, store user accounts, call an LLM, or process production data.

Security reports are still welcome for issues involving the application source, dependency configuration, deployment behavior, or bundled assets.

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data, or sensitive reproduction steps in a public issue.

Use GitHub's private **Report a vulnerability** flow when it is available for this repository. If that option is not available, open a minimal public issue asking for a private reporting channel without including sensitive details.

A useful report includes:

- affected version or commit;
- affected route or component;
- impact and realistic attack conditions;
- minimal reproduction steps;
- suggested mitigation, when known.

## Out of scope

- Claims that the simulated agents are not real autonomous workers; this is documented behavior.
- Third-party sprite ownership disputes that are not caused by repository code.
- Social engineering, denial-of-service testing, or testing against infrastructure you do not own or have permission to assess.
